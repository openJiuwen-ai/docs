# openJiuwen 术语表

本文档收录 openJiuwen 社区与平台常用术语，便于新用户快速上手。

| 术语 | 英文全称 | 说明 |
| --- | --- | --- |
| Agent | 智能体 | 能够感知环境、自主决策并执行任务的智能程序 |
| Agent Runtime | 智能体运行时 | 承载 Agent 运行、调度与资源管理的运行环境 |
| Agent Studio | 智能体工作室 | 面向 Agent 开发、调试与部署的可视化工具 |
| Tool | 工具 | Agent 可调用的外部能力，如搜索、API 调用等 |
| Skill | 技能 | 封装好的可复用能力单元，Agent 可按需装配 |
| Swarm | 群体智能 | 多 Agent 协同完成复杂任务的编排模式 |
| DeepSearch | 深度搜索 | 知识增强的深度搜索与研究框架 |
| SIG | Special Interest Group | 社区中围绕特定方向组建的兴趣小组 |
| CLA | Contributor License Agreement | 贡献者许可协议，签署后方可合入代码 |
| CoC | Code of Conduct | 社区行为准则 |
| Coordination Engineering | 协同工程 | 面向多智能体协同的工程方法论 |
| JiuwenClaw | 久闻之爪 | 面向团队协同技能的新一代 Agent 能力组件 |
| 昇腾 / 鲲鹏 | Ascend / Kunpeng | 华为自研 AI 算力与通用算力平台，openJiuwen 对其具备天然亲和性 |

> 如发现遗漏或释义有误，欢迎提交 Issue 或 PR 完善本表。
